26.11.24
+ added a JSON/JSONC/JSON5 minifier (`src/minifier/json/`) that strips comments, whitespace and trailing commas while copying string contents verbatim. Single quotes and unquoted JSON5 keys are tolerated. Added 21 unit tests.
+ added a CSS/SCSS/LESS minifier (`src/minifier/css/`) that removes comments, collapses whitespace, preserves descendant selector spaces, keeps `calc()` operator spacing, protects quoted strings and unquoted `url(...)` contents, and drops redundant semicolons before `}`. Added 22 unit tests.
+ added a configurable C-like lexer/minifier (`src/minifier/c_like/`) with per-language profiles for JavaScript/TypeScript/JSX/TSX, Java, Kotlin, Groovy/Gradle, Scala, C, C++, C#, Objective-C, Go, Swift, Dart, PHP, Lua, Proto, Thrift, FlatBuffers, Avro, Elixir, Erlang, Clojure, OCaml, Pascal, Crystal, Solidity, CUDA, Verilog, VHDL, GLSL, OpenCL, QML, `.strings`, Zig and D. Comments are removed first; strings, regex literals, raw/verbatim/triple/long-bracket literals are protected. JavaScript-like languages get safe automatic semicolon insertion at newlines.
+ added `MinifierOptions` with a `preserve_line_breaks` override and added `minify_with_options`.
+ added 27 unit tests for the C-like engine.
+ added a data-driven language registry (`src/minifier/language.rs`) with support detection by extension, exact file name and file name prefix, plus source sniffing for ambiguous `.config`, `.m`, `.inc` and `.lock` files. This is the foundation for the new file types; the old Rust/TOML paths still behave as before.
+ added unit tests for the registry.

26.10.26
+ adding `--soft-split` (for `--concat-to`) which tries to re-distribute the content of single output file. it only re-distribute minified-files, not breaking their content. limit is set to number of characters assuming utf8.

26.10.19
* old `concat_output`+`concat_to_stdout` -> `--concat-to` (default `STDOUT`). writes to path or STDOUT.
* support directory paths in arguments, it is flatten at runtime, recursive directory-walk discover all `.rs` and `.toml` files. combined with `--concat-to` it can be used to generate a single file at the root of the project of all the minified files with ease (that's the whole point of it).
* after the minified content, adding two EOL (OS `\r\n` or `\n`) - helps when joining multiple files. note that comments are still suitable per-content even if you'll join .rs (//) and .toml(#) together, for holding the file path.
* include more information while processing files.
* deterministic order when using `--concat-to` by waiting for all threads to first finish digging though all directories, then writing all toml files first (sorted by their paths naturally) then the rust files (also sorted by their paths naturally). the dig step is still none-deterministic but we wait for all to finish before using one write to the output (keeps all in RAM until then..), the non `--concat-to` is still as before, as a thread finish it writes its own file.
* adding `--exclude` (can be used multiple times), matches not in case-sensitive way, a part of filename (not extension, not path). a good way to avoid including `tests.rs` in your result.
