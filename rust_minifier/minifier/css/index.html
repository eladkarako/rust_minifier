CSS, SCSS and LESS minifier.

Selector descendant spaces are meaningful, so the reconstruction step is context aware: it keeps spaces between words and around selector colons, while removing them around braces, commas, semicolons and declaration colons. url(...) contents are protected because an unquoted URL can contain //.
