PHP minifier for mixed HTML/PHP documents.

PHP files interleave HTML with <?php ... ?> blocks. Each PHP block is minified as code, while the surrounding document is minified as HTML. PHP blocks are replaced with private-use placeholders during HTML minification so whitespace around them is handled correctly, then restored afterwards.
