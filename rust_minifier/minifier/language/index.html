Module language 

Source
Expand description

Data-driven registry of every file type this program knows about.

The registry is intentionally a plain table of Language records. Adding a new file type should usually be a one-line change here, not a new engine. Each record names the engine that knows how to minify the syntax and the comment style used when a source path is embedded in concatenated output.
