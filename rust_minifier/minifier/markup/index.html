rust_minifier::minifier

Module markup 

Source
Expand description

HTML, XML, SVG and single file component minifier.

The engine removes comments, collapses whitespace in text nodes while respecting inline elements, normalizes tags and attributes, preserves <pre>/<textarea> contents, and minifies embedded <script>/<style> blocks with the matching engine. Template regions such as {{ }}, {% %}, <% %>, @{ } and <? ?> are treated as opaque so their contents are not rewritten.
